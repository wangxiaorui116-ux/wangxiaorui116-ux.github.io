# 王骁睿 · 个人作品集

王骁睿（WANGXIAORUI）的个人网站，基于 Next.js 构建并通过 GitHub Pages 发布。

当前内容包括：

- 个人介绍与关注方向
- NUS SoC 实时人脸与人体关键点分析项目
- 2026 华数杯微构体导电仿真优化项目
- 经历与 GitHub 联系方式
- 桌面端和移动端自适应布局

## 本地预览

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm run lint
npm test
```

提交到 `main` 分支后，GitHub Actions 会自动构建并更新网站。
